# LinkPilot 1.4.2

Download `LinkPilot.exe` and run it normally. No Python, Playwright, browser install, source plugin setup, proxy plugin setup, or CAPTCHA plugin file setup is required for the bundled defaults.

This release includes:

- Playwright Chromium, Chromium Headless Shell, and ffmpeg.
- Default local plugin folders for sources, proxies, and CAPTCHA providers.
- LinkPilot logo/photo assets.
- Packaged helper scripts used by login priming and sidecar commands.

Local user data is intentionally not included in the public artifact: saved links, UI state, encrypted secrets, browser profiles, logs, env files, and local caches remain private to each installation.
